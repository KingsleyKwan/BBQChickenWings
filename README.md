# 燒雞翼

Motion-first Hong Kong BBQ mid-wing sim. Sit at a charcoal stove and hold a long fork: phone tilt is fork height and sweep, twist turns the fork.

- Pick one mid-wing from a bag (about 78g / 96g / 118g).
- Line the two tines up with the two bones, then hold 吉 to pierce.
- Roast, glaze, roast again, plate, pull the fork, then get a score.

Cooking math lives in `src/game/` (`sim.ts`, `scoring.ts`, `constants.ts`). Auth and database stay off.

```bash
npm install
npm run dev
```
